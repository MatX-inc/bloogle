Bloogle is a Bluespec API search engine, which allows you to search the Bluespec standard libraries by either function name, or by approximate type signature.

Example searches:
mkReg
(a -> b) -> Vector n a -> Vector n b
Vector n a -> a
Get
m (FIFO a)

Enter your own search at the top of the page.

Type search tips:

  • matches by exact arity: a -> a won't find a -> a -> a
  • unifies type variables and ignores argument order
  • _ wildcards a single argument's type

Bloogle is built on Hoogle, so the full Hoogle search syntax works here too:

  • map searches as text, finding map, mapM, mapPairs
  • mk reg searches for both words, finding mkRegU but not mkFIFO
  • a -> a searches by type, finding id :: a -> a
  • :: a forces a type search for "a"; a bare a searches as text
  • id :: a -> a searches for the text "id" and the type "a -> a"
  • fold +Vector restricts results to the Vector module; reg -Vector excludes it
